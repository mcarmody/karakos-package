A standing Claude agent for your household — not a script you rebuild every week.

Persistent agents need session lifecycle management, memory consolidation, cost guards and orchestration before you get to the part you actually wanted. Karakos ships all of it in one Docker install. Point it at a Discord server and an Anthropic key, and you get an assistant that remembers, costs what you tell it to, reaches you where you already are, and can safely extend its own code.

Install in one command View on GitHub

Install

The installer handles Docker, Git and jq, clones the repo, runs the setup wizard, pulls the prebuilt image from GHCR and starts the system.

$ curl -fsSL https://raw.githubusercontent.com/mcarmody/karakos-package/main/install.sh | bash
PS> irm https://raw.githubusercontent.com/mcarmody/karakos-package/main/install.ps1 | iex

When it finishes, open http://localhost:3000. Windows needs an elevated PowerShell.

What you get

Six pieces of infrastructure that are individually unremarkable and collectively the reason most hobby agents never make it past a weekend.

💬

Discord-native

Agents answer in the server you already sit in — per-channel, with attachments, slash commands, and typing indicators that tell you a turn is actually running.

🖥️

Local dashboard

A web UI at localhost:3000 for chat, health, agent status and live monitoring. No cloud tenant, no account, nothing leaves the box but the API calls.

🧠

Episodic memory

Conversations are consolidated into durable memories with semantic recall, so the agent knows what you told it last Tuesday without you pasting it again.

🔁

Session persistence

Context survives restarts, upgrades and crashes. A container bounce is an interruption, not amnesia — and unexpected respawns are announced, not swallowed.

💸

Cost tracking & guards

Per-agent spend tracking with configurable limits. Typical household usage runs $5–15/week, and you set the ceiling rather than discovering it on a statement.

🛠️

Self-modifying, safely

Builder and reviewer agents can change the system's own code behind guardrails — protected paths and tiered review — so it extends itself without corrupting its own process.

Requirements

One always-on machine. A Raspberry Pi 5 is enough; a spare laptop is plenty.

Hardware4 GB RAM minimum (8 GB recommended), 2+ CPU cores, 10 GB disk
Operating systemUbuntu 22.04+, Debian 12+, macOS 12+, Windows 10/11
SoftwareDocker Engine 24+ with Compose v2
AccountsAn Anthropic API key and a Discord bot token
NetworkStable outbound internet for Anthropic API calls
Runtime24/7 recommended — the point is that it is standing, not summoned
Expected cost$5–15/week for typical household usage
